> 尖括号\>是引用 

>很多
>尖括号
>>是引用块（可以嵌套）

上述引用可以更完美地被下面标注替代

> [!Note] Callout 
> 这是标注，用于醒目地强调
> 
> 也就是引用的尖括号\>之后再加方括号内一个感叹号 [!...]，后跟题目
> 
> 共有12种不同的类型：(大小写无所谓)
> 
> 将下方单词替换[!...]的...即可
> 1. note
> 2. abstract, summary, tldr
> 3. info, todo
> 4. tip, hint, important
> 5. success, check, done
> 6. question, help, faq
> 7. warning, caution, attention
> 8. failure, fail, missing
> 9. danger, error
> 10. bug
> 11. example
> 12. quote, cite 
>> [!tip]
>> 同样可以级联嵌套
>
>还可以折叠，只需在 ] 后面加一个 - 或+ ，注意后跟空格
>“-”是默认折叠
>“+”是默认展开
>>[!example]- Example 1
>>
>>这是折叠的例子
>
>>[!example]+ Example 2
>>
>>这是展开的例子

# 链接

## 内部链接

### 跳转
**页内跳转：**

1. 跳转到同一篇笔记的不同段落：
	
    \[\[ ]]内输入#，然后输入标题名字
    
    | 后可自定义名字
    
    [[#链接 | 这是链接]]

2. 跳转到同一篇笔记的不同段落：
	
    \[\[ ]]内输入^，然后输入段落文字
    
    | 后可自定义名字
    
    [[#^052659 | 这是分界线]]

**页外跳转**

1. 跳转到其他笔记
	
	内输入笔记名字
	
	| 后可自定义名字
	
	[[00_Markdown_index| 这是Markdown索引]]

2. 跳转到其他笔记的具体标题段落
	
	1. 跳转到标题
		
		只需笔记名后加#即可
		
		| 后可自定义名字
		[[00_Markdown_index#导言| 这是Markdown索引的导言标题]]
	
	2. 跳转到段落
		
		只需笔记名后加^即可
		
		| 后可自定义名字
		[[00_Markdown_index#^4211a2| 这是Markdown索引的其中一小段]]

## 外部链接

访问外部的网站，语法是\[]()，其中\[]内写名字，()内写网址

比如：

 [个人博客](https://xumintian.cn/)

[Google](https://www.google.com)

## 脚注

有两种方式来实现：

**第一种**

在想插入脚注的地方后，打下\[\^1]
然后再笔记最下方或原来行空一行同样的打下\[\^1]和：[^1]

[^1]:这是第一条脚注

**第二种，也是更推荐的一种**

直接在想插入脚注的地方后，打下\^\[]，中括号里面直接写注释
因为这样最省事[^2]

**其他功能**

脚注竟然也可以像其他链接手段一样，实现跳转[^3]

# 快捷键

- 加粗:
    - Ctrl + B 
- 斜体:
    - Ctrl + I
- 打开命令面板:
    - Ctrl + P
- 快速切换:
    - Ctrl + O
- 查找:
    - Ctrl + F
- 切换 *编辑* / *阅读* 模式:
	- Ctrl + E
- 打开设置:
	- Ctrl + ，
- 添加笔记属性:
	- Ctrl + ；  
- 添加注释:
	- Ctrl + /
- 关闭当前标签页:
	- Ctrl + W
- 创建新的笔记:
	- Ctrl + N
- 创建代办事项:
	- Ctrl + L
- 打开 / 关闭左边栏:
	- Alt + L
- 打开 / 关闭右边栏:
	- Alt + R
- 插入模板:
	- Alt + I
