# 导言说明

我应该在这里先简要说明一下我都**学了什么**, **要学什么**, **怎么学**等等

然后是导航到不同的学习区块的索引, 在那里更详细的说明具体科目

**以写促学**, **费曼学习法**, **反结构主义**, 这应该是我学习的关键词

**以写促学**:

也就是, 强调 *输出* ,逼着自己完成小项目, 项目结案, 而不是看完拉到.
输出和输入同样重要, 输出的过程就是内化的过程, 也许漏洞百出, 也许提笔忘字, 也许卡壳, 
That's all right, 没关系, *尽情犯错*, 这里又不是考试, *关键是心态上*, *承认*不断地在学习阶段犯错, 不断地体会挫败但是同时告诉自己这没关系, 要是自欺欺人那就是永远原地踏步. 


可以先写得很拙劣, 然后再慢慢改正. 先做出一块石头, 再慢慢雕刻成玉.

**费曼学习法**

这个很多人都很熟悉, 我的实践就是:"*过去的自己教会未来的自己*", 未来必定会有遗忘, 时间一长好像全还了一样, 这个时候就是看看过去的笔记, 让过去的笔记教会未来的自己

**反结构主义**

我发现结构主义总是失败，遵循结构主义就像是表演给某个人看的，表演给这个结构本身看的，而自己好像没有内化，对于教材, 对于笔记都是这样的

好像非要找到一个完美的教材,视频, 非要所谓"完整地学习", 或者非要1, 1.1, 1.1.1 这样才放心一样, 越是这样越学不会, 学习是可以先不管那些看不见的结构主义的, 先把手弄脏, 别管大的, 宏观的, 每个关系都要弄明白? 别这样了, 只要学了就是吃进肚子里了, 无需担心.
